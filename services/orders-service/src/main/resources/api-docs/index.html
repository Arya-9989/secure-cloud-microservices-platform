orders-service

Orders API reference.

Browse the catalog, place and cancel orders, and run fulfilment. Every call carries a bearer token from auth-service, and its scopes decide what it may do.

  • Scopes orders:read orders:write orders:admin
  • Errors as application/problem+json
  • Prices set by the server
