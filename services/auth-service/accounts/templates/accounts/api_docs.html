auth-service

Auth API reference.

Register, log in and rotate refresh tokens. Access tokens are RS256 JWTs that any service can verify against the public keys at /.well-known/jwks.json.

  • Bearer JWT, RS256
  • Errors as application/problem+json
  • Rate limited per IP and per account
